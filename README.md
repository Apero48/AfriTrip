# 🌍 AfriTrip

**AfriTrip** est un comparateur de voyage mondial nouvelle génération, conçu pour offrir les meilleurs tarifs sur les vols, hôtels, locations de voitures et activités touristiques partout dans le monde.

![AfriTrip Banner](public/placeholder-flight.jpg)

## 🚀 Fonctionnalités

*   **✈️ Comparateur de Vols** : Recherche en temps réel parmi des centaines de compagnies aériennes.
*   **🏨 Hôtels & Hébergements** : Accès à des millions d'offres d'hôtels, appartements et villas.
*   **🚗 Location de Voitures & Transferts** : Solutions de mobilité complètes.
*   **activity Tours & Activités** : Réservation d'excursions et d'expériences locales.
*   **🔍 SEO Optimisé** : Architecture technique avancée pour une visibilité maximale (Sitemap, JSON-LD, Metadata dynamiques).
*   **📱 Mobile First** : Expérience utilisateur fluide sur tous les appareils.
*   **🎨 Design Premium** : Interface moderne avec effets Glassmorphism (macOS style).

## 🛠 Technologies

*   **Framework** : [Next.js 15](https://nextjs.org/) (App Router)
*   **Langage** : [TypeScript](https://www.typescriptlang.org/)
*   **Styling** : [Tailwind CSS](https://tailwindcss.com/)
*   **Icons** : [Lucide React](https://lucide.dev/)
*   **Monétisation** : Intégration [Travelpayouts](https://www.travelpayouts.com/)

## 📦 Installation

1.  **Cloner le projet**
    ```bash
    git clone https://github.com/Apero48/AfriTrip.git
    cd AfriTrip
    ```

2.  **Installer les dépendances**
    ```bash
    npm install
    ```

3.  **Lancer le serveur de développement**
    ```bash
    npm run dev
    ```
    Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## 🚀 Déploiement

Le projet est optimisé pour un déploiement sur [Vercel](https://vercel.com).

1.  Poussez votre code sur GitHub.
2.  Importez le projet dans Vercel.
3.  Configurez la variable d'environnement :
    *   `NEXT_PUBLIC_SITE_URL` : L'URL de votre site (ex: `https://afritrip.com`)
4.  Déployez !

## 📄 Structure du Projet

*   `/app` : Pages et routes de l'application (Next.js App Router).
*   `/components` : Composants Réutilisables (UI, Features, Layout).
*   `/lib` : Utilitaires et données statiques.
*   `/public` : Assets statiques (images, fonts).
